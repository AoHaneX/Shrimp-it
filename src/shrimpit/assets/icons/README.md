# Icônes

Icônes de navigation fournies : `home.png`, `image.png`, `expand.png`, `history.png` et `settings.png`,
en PNG carrés transparents de 256 px. Elles sont affichées entre 25 et 58 px.

Les icônes `menu`, `upload`, `folder` et `close` sont dessinées par Qt dans `gui/theme.py`. Un PNG
du même nom placé dans ce dossier les remplace ; relancer l’application après tout remplacement.
